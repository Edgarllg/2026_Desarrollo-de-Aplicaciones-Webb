Quiénes somos

AutoDrive es un sistema web desarrollado como proyecto académico para la gestión integral de un concesionario de vehículos. Permite administrar el catálogo de vehículos, la cartera de clientes, la red de proveedores y el proceso de facturación, todo con persistencia real de datos y control de acceso mediante autenticación de usuarios.

  • Control de inventario de vehículos en tiempo real
  • Gestión de clientes y proveedores
  • Facturación con historial detallado
